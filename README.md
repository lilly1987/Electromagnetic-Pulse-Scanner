# ElectromagneticPulseGenerator

A RimWorld mod that adds an Electromagnetic Pulse Generator building.

## Features
- Scans for ore deposits
- Custom building and job definitions
- Configurable scan timing in the mod settings

## Installation
1. Clone or download this repository.
2. Place it in your RimWorld Mods folder.

## Scan settings
Open the mod settings to adjust the mean time between finds and the guaranteed scan limit. These settings apply to both the powered scanner and the Save Our Ship 2 passive scanner.

The RimWorld 1.7 source is in `Source/1.7` and builds to `1.7/Assemblies`.
